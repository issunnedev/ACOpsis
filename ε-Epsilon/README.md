# ε-Epsilon Modified ZETA with Youtube API integrated to alter the output

This uses the Youtube API V3 to gather the top 100 related to the prompt and feed it to a modified version of Zeta.

### This requires ζ-Zeta model to be installed in the same parent directory (this is usually already the case due to them being packaged together)

### Requirements:
Nvidia GPU with Tensor cores and minimum 6GB VRAM (Tested on RTX 3060 Laptop GPU)
16GB RAM DDR4/DDR5 (DDR3 or below may be too slow)
Decently Fast SSD or HDD (NVMe SSD recommended)
Moderate CPU
Fast LAN/wLAN
